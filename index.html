📖 使用帮助
🚀 快速开始
  1. 首次使用可在「设置」中开启 演示模式 直接体验，或填写你的 API 地址。
  2. 选择 文生图 或 图生图 模式，输入提示词。
  3. 调整参数（步数、CFG、尺寸、种子等），点击「立即生成」。
  4. 结果会自动保存到下方画廊，可点击查看、下载、复用参数。
🔧 常见错误排查
  • 503 model_not_found / 无可用渠道：中转分组下该模型不可用。到「设置」修改「OpenAI 模型名称」为后台实际支持的名字（如 dall-e-3），或联系 API 提供方。
  • 401 / Incorrect API key：密钥错误或额度不足。
  • Failed to fetch：地址不可达，或 API 未开启 CORS（浏览器直连需服务端允许跨域，可用本地代理转发）。
  • 超时：在「设置」中增大超时时间（批量/高分辨率生成耗时更长）。

💡 提示
  • 使用风格标签或「灵感」按钮快速填充高质量提示词。
  • 锁定种子可复现完全相同的画面，便于微调提示词。
  • 画廊最多保存 50 张，超出会自动移除最旧的作品。
  • 所有数据仅存于本地浏览器，关闭页面不会上传。
